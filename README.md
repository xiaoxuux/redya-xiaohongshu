# redya-xiaohongshu

红鸦AI-skill：小红书图文批量生成与发布（Claude Code skill）。

输入一句话或粘贴小红书图文、公众号文章、抖音快手视频链接，就能生成标题、正文和配图，支持一步出图、批量创作、爆文复刻、Live 实况图文和敏感词检测。成稿可通过插件发布到小红书、抖音、公众号等多平台。

## 安装

将本仓库的 SKILL.md 与 references/ 复制到 `~/.claude/skills/redya-xiaohongshu/`，或在 Claude Code 对话中直接使用。

API Key 在 https://hy.ithinkai.cn/developer 获取。
